| العنصر | النتيجة المرصودة |
|---|---|
| البطاقتان الرئيسيتان | بعرض 552px وارتفاع 230px، الأولى داكنة والثانية ذهبية بقيم الهوية الأصلية. |
| البطاقات الثانوية | ست بطاقات بعرض 268px وارتفاع 201px، موحّدة الحواف `28px` والمسافات. |
| الشبكة | 12 عمودًا، gap `16px`، عرض إجمالي 1120px. |
| الهوية | backgrounds الداكن والذهبي وsatin surfaces مطابقة لقيم Sakina Pro. |
| overflow أفقي | غير موجود. |
| المصدر | Sakina Pro تمت قراءته فقط ولم يتغير. |

تم تحديث بنية البطاقات لتكون هرمية بدل شبكة مسطحة: بطاقتا أذكار الصباح والمساء هما نقطتا التركيز، وتأتي بقية الأذكار في صف ثانٍ متوازن. توجد media queries للتحول إلى عمودين ثم عمود واحد على الشاشات الصغيرة.
