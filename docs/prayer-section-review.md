# Prayer section review

تمت مراجعة النسخة المبنية من قسم «صلاتك في وقتها» بعد إعادة بناء المكوّن.

القسم أصبح مكوّنًا من عمود محتوى وعمود لوحة مواقيت، بدل حلقة عائمة محاطة بفقاعات منفصلة. لوحة المواقيت تستخدم surface زجاجية من Sakina Pro، وبداخلها رأس اليوم والموقع، بطاقة الصلاة الحالية مع الحلقة، ثم جدول المواقيت القادمة في شبكة ثنائية.

النتائج المرصودة في نسخة سطح المكتب:

| القياس | النتيجة |
|---|---|
| عرض قسم الصلاة | 1265px |
| عرض لوحة المواقيت | 510px |
| ارتفاع البطاقة الحالية | 184px |
| ارتفاع كل بطاقة ميزة | 55px |
| عدد عناصر `.prayer-pill` القديمة | 0 |
| overflow أفقي | غير موجود |
| نصف قطر لوحة المواقيت | 28px |
| لون الخلفية | `#ece7de` من هوية Sakina Pro |

تم الحفاظ على قيم glass الأصلية: تدرج surface، حدود espresso الدقيقة، ظلال الارتفاع، وradius 28px للبطاقات. وتمت إضافة media queries لتتحول اللوحة إلى عمود واحد على الشاشات الأصغر مع بقاء جدول المواقيت منظمًا.
