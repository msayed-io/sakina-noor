# Visual system verification

تمت مراجعة نسخة الإنتاج المحلية بعد استبدال طبقة التصميم المضافة بطبقة Sakina Pro الأصلية.

| العنصر | القيم المرصودة |
|---|---|
| الهيدر `.nav` | `blur(26px) saturate(210%)`، تدرج Sakina Pro، حدود `rgba(43,26,16,.09)`، radius `9999px`، وظل/لمعة القيم الأصلية. |
| الكبسولة العلوية | تدرج Sakina Pro، blur `30px`، حدود `rgba(43,26,16,.10)`، radius `9999px`. |
| البطاقة الفاتحة | `blur(20px) saturate(160%)`، تدرج satin الأصلي، radius `28px`، وظل Sakina Pro. |
| البطاقة الداكنة | تدرج `rgba(43,26,16,.95)` إلى `rgba(27,16,10,.98)`، حدود ذهبية `rgba(222,171,101,.35)`، وظل dark capsule الأصلي. |
| البطاقة الذهبية | اللون الأصلي `#deab65` وحدود وظل gold capsule الأصلي. |
| صفحة المصحف | بقيت scoped على `QCF_P001`، ولا تستقبل خط أو نظام ألوان البطاقات. |
| التمرير الأفقي | لا يوجد overflow أفقي في نسخة سطح المكتب. |

المصدر المرجعي للمعايرة هو `src/index.css` في نسخة القراءة فقط من Sakina Pro. حالة المستودع المصدر بقيت نظيفة.
