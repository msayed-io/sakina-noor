# Sakina — Islamic Spiritual Companion Landing Page

صفحة هبوط عربية لتطبيق **سكينة**، وهو رفيق روحي يومي يجمع الصلاة والأذكار والقرآن وحصن المسلم في تجربة هادئة ومتجاوبة.

## المميزات

- تصميم عربي كامل باتجاه من اليمين إلى اليسار (RTL).
- واجهة هبوط متجاوبة مستوحاة من تطبيقات الهاتف الحديثة.
- أقسام تعريفية للصلاة، القرآن، الأذكار، والإحصاءات.
- تأثيرات حركة وتمرير وتفاعل بصري لعرض الهاتف.
- مبني باستخدام Next.js وReact وTypeScript وTailwind CSS.

## التشغيل محليًا

يتطلب المشروع Node.js 20+ وBun أو npm.

```bash
bun install
bun dev
```

بعدها افتح `http://localhost:3000`.

## أوامر مفيدة

```bash
bun run lint
bun run build
bun start
```

## ملاحظات

هذا المستودع يحتوي على واجهة صفحة الهبوط ومكوناتها. لا يتم تضمين ملفات البيئة أو قواعد البيانات المحلية أو مخرجات الاختبار في المستودع العام.
